# SocialBook - Laravel Social Media Web Application

## 📌 Overview

SocialBook is a full-featured social media web application built with Laravel.  
It is inspired by modern social platforms and provides users with interactive community features similar to Facebook.

The platform allows users to connect, share content, communicate, and participate in a secure online marketplace.

---

## 🚀 Features

### 👤 Authentication & Security
- Secure Login & Signup System
- Password Protection & Validation
- Authenticated User Sessions

### 📰 Posts & Feed
- Create, Edit & Delete Posts
- News Feed to view posts from other users
- Like, Comment & Share functionality
- Search posts and users

### 👥 Friends System
- Send & Receive Friend Requests
- Accept / Reject Friend Requests
- View Friends List
- View Other Users’ Profiles (Bio, Posts, Info)

### 💬 Real-Time Chat System
- Built-in private messaging system
- Start chat with friends
- Send & receive messages instantly

### 🛒 Marketplace
- Buy & Sell Items within the SocialBook Community
- Marketplace Listings
- Safety & precaution measures for transactions

### 🤖 ChatBot Feature
- AI-powered chatbot system
- Users can interact and ask questions similar to ChatGPT

### 👨‍👩‍👧‍👦 Groups System
- Public & Private Groups
- Join or Request to Join Groups
- Admin can add/remove members
- Group-based posts and discussions

### 🔎 Search System
- Search users
- Search posts
- Discover content easily

## ⚙️ Installation Guide

1. Clone the repository:

   git clone https://github.com/yourusername/socialbook.git

2. Navigate to project folder:

   cd socialbook

3. Install dependencies:

   composer install

4. Create .env file:

   copy .env.example .env

5. Generate application key:

   php artisan key:generate

6. Configure database in .env file

7. Run migrations:

   php artisan migrate

8. Start development server:

   php artisan serve
